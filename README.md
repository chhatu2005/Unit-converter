# Day 15 – Unit Converter

## Project Overview
The Unit Converter is a simple and responsive web application developed using HTML, CSS, and JavaScript. It allows users to convert different units of length and weight quickly and easily.

## Objectives
- Practice JavaScript functions and conditional statements.
- Understand form handling and DOM manipulation.
- Learn how to perform mathematical conversions.
- Create a responsive and user-friendly interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Convert length and weight units.
- Dropdown menus for selecting conversion units.
- Live conversion as the user enters a value.
- Supports at least four units in each category.
- Displays results rounded to four decimal places.
- Reset button to clear the input.
- Responsive design for mobile and desktop devices.

## Supported Units

### Length
- Meter
- Kilometer
- Feet
- Mile

### Weight
- Kilogram
- Gram
- Pound
- Ounce

## How to Run the Project

1. Clone this repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_LINK
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Select a category (Length or Weight).

5. Enter a value and select the source and target units.

6. The converted result will be displayed automatically.

## How It Works
The application uses JavaScript functions to calculate conversions. Each unit has a conversion factor relative to a base unit. The program first converts the input value to the base unit and then converts it to the selected target unit.
